# TLS Сертификаты для Fakequasar

В целях соблюдения авторских прав и безопасности приватные ключи и TLS-сертификаты **не распространяются в составе данного репозитория**.

Для работы сервера `fakequasar` (локальная эмуляция сервера обновлений `quasar.yandex.net`) вам необходимо самостоятельно предоставить и разместить в этом каталоге следующие файлы:

1. `fullchain_with_root.pem` — цепочка сертификатов для домена `*.quasar.yandex.net`.
2. `quasar-all.key` — приватный ключ сертификата.

### Где взять или как подготовить:
* **Энтузиастские сообщества:** Готовые комплекты сертификатов и дампов для Fakequasar можно найти в профильных темах на 4PDA или Telegram-каналах разработчиков для Яндекс Станции.
* **Собственный центр сертификации (CA):** Вы можете сгенерировать собственный корневой сертификат с помощью `openssl`, подписать wildcard-сертификат для `*.quasar.yandex.net` и добавить ваш root CA в список доверенных сертификатов Станции (`/system/etc/security/cacerts/` через монтирование Dropbear).
